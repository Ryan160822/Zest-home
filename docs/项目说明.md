# Zest 个人主页 · 项目说明

> 这份文档是项目的完整说明，独立可读——即使没有当时的对话记录，看这份也能接着维护。

## 一、这是什么

一个个人主页，玻璃质感（glassmorphism）暖色 Bento 风格，纯静态前端 + 一个轻量 Cloudflare Worker 接口。

- **线上地址**：https://zest.awuxx.de （域名托管在 Cloudflare）
- **代码仓库**：https://github.com/Ryan160822/Zest-home （SSH 推送）
- **托管/部署**：Cloudflare（Workers + 静态资源模式），连接 GitHub，**每次 `git push` 自动重新部署**

主页包含：个人介绍、当前状态、GitHub 数据、两个可用小工具、北京时间、随机中英双语金句、每日 AI 日报。

## 二、文件结构

```
个人主页/
├── public/                  ← 网站静态文件（部署的根目录）
│   ├── index.html           ← 页面骨架（导航、背景层、空的 #bento、页脚容器）
│   ├── styles.css           ← 全部样式 + 设计 token（:root 里的 CSS 变量）
│   ├── main.js              ← 内容数据(SITE) + 所有卡片的渲染逻辑
│   └── tools/
│       ├── tools.css        ← 工具页通用样式（复用主题）
│       ├── qr.html / qr.js  ← 二维码生成器
│       └── prompts.html / prompts.js  ← Prompt 模板库
├── worker.js                ← Cloudflare Worker 入口：处理 /api/daily，其余交给静态资源
├── wrangler.toml            ← 部署配置（见下）
├── docs/                    ← 设计文档、实现计划、本说明（不会被部署）
└── .gitignore               ← 忽略 .DS_Store / .superpowers / .claude 等本地文件
```

## 三、部署是怎么运作的

项目按 **Cloudflare Workers + 静态资源** 方式部署（不是经典 Pages）。`wrangler.toml`：

```toml
name = "zest-home"
main = "worker.js"
compatibility_date = "2024-09-23"

[assets]
directory = "./public"
binding = "ASSETS"
```

- Cloudflare 连了 GitHub，构建时执行 `npx wrangler deploy`
- `main = "worker.js"`：Worker 入口
- `[assets] directory = "./public"`：把 `public/` 当静态网站托管
- 请求逻辑（见 `worker.js`）：`/api/daily` 由 Worker 处理；其他所有请求 → 静态文件

**更新上线**：在本机改完代码 → `git push origin main` → Cloudflare 自动部署（约 1–2 分钟）。

## 四、怎么改内容（最常用）

绝大多数内容都集中在 **`public/main.js` 顶部的 `SITE` 对象**，改这里即可：

- **个人信息**：`SITE.profile`（姓名、首字母头像、身份、简介、标签）
- **当前状态**：`SITE.status`
- **GitHub 数据**：`SITE.github`（目前是手填的数字）
- **工具卡**：`SITE.tools`（图标、名称、`href` 链接到工具页）
- **随机金句**：`SITE.englishQuotes`（`{ en, zh }` 数组，每次刷新随机一句）
- **AI 日报链接**：`SITE.aihot.href`
- **页脚标语**：`SITE.footerTagline`
- **社交链接**：`SITE.social`
  - 当前：GitHub `https://github.com/Ryan160822`、Telegram `https://t.me/ZestWit`
  - 邮箱已移除；想加回：在 `social` 数组里取消注释那行并填地址（`mail` 图标已保留在 `ICONS` 里）
  - 加新平台：在 `social` 加一项，并在 `ICONS` 对象里补一个对应的 SVG，`icon` 字段对应键名

## 五、两个小工具

- **二维码生成器** (`public/tools/qr.html` + `qr.js`)：输入文字/链接实时生成，可选尺寸和容错级别，下载 PNG。
  - 依赖 CDN：`https://cdn.jsdelivr.net/npm/qrcode@1.5.1/build/qrcode.min.js`（**版本号要用确实存在的**，见踩坑）
- **Prompt 模板库** (`public/tools/prompts.html` + `prompts.js`)：增删改查、搜索、一键复制；模板里写 `{{变量}}` 可弹出填空再复制。数据存浏览器 `localStorage`（键名 `zest_prompts`），首次打开有 3 个示例。

## 六、每日 AI 日报是怎么实现的

数据源 `https://aihot.virxact.com/api/public/daily` **没有开 CORS**，浏览器不能直连。所以：

1. `worker.js` 里 `/api/daily` 在**服务器端**去取那个接口（服务器端无跨域限制），加 15 分钟缓存，返回 JSON。
2. 主页 `main.js` 的 `loadAihot()` 请求**同源**的 `/api/daily`，拿到后渲染出今天的标题列表（取前 6 条，按 `sections[].items[]` 展开，每条 `title / sourceUrl / sourceName`）。
3. 若取不到（如本地预览没有 Worker 运行时），降级成"前往 AI 日报"的链接。

## 八、视觉设计系统

- **风格**：玻璃拟态 Bento 网格（4 列，混合 1×1 / 2×1 / 2×2 等卡片，响应式 4→2→1）
- **字体**：标题 `DM Serif Display`（衬线），正文 `Nunito`（圆润）
- **配色**：暖白渐变背景 + 4 团淡雅光斑；卡片半透明磨砂玻璃 + `backdrop-filter`；各区块用淡色"有色玻璃"做分类
- **设计 token**：都在 `styles.css` 的 `:root` 里（`--glass-*`、`--c-*` 分类色、`--accent`、字号间距等）
- **无障碍**：文字对比度按 WCAG 调到 ≥ 4.5:1；支持 `prefers-reduced-motion`；可点元素有 `:focus-visible` 焦点态

## 九、踩过的坑（重要，避免重蹈覆辙）

1. **Workers vs Pages**：本项目用 `npx wrangler deploy`（Workers 模式）。Pages 专属的 `functions/` 目录在这里**不生效**——服务器端接口要写在 `worker.js` 里，并用 `[assets]` 托管静态文件。
2. **AIHOT 接口无 CORS**：必须服务器端代理（`worker.js`），不能浏览器直连。
3. **二维码 CDN 版本**：`qrcode@1.5.4`、`@1.5.3` 的 `build/qrcode.min.js` 路径是 404；用 **`@1.5.1`**（已验证可用）。换版本前先 `curl -I` 确认地址存在。
4. **Cloudflare HTTPS"不安全"**：HTTPS 证书没问题，但要在 Cloudflare **SSL/TLS → Edge Certificates → Always Use HTTPS** 打开，让 `http://` 自动跳 `https://`。
5. **配置/历史目录**：Claude Code 的配置会生成在"启动命令的目录"。建议在 `个人主页/` 里启动，配置就落在 `个人主页/.claude/`（已 gitignore），不污染别处也不进仓库。
