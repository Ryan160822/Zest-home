# 个人主页 · 设计文档

**日期：** 2026-05-30
**作者：** James

## 目标

一个综合型个人主页，集中展示：

- **个人介绍**：谁、在做什么
- **小工具**：自己做的实用小工具入口
- **VIBE CODING 作品**：用 AI 构建的项目
- **文章**：记录值得分享的思考

面向各类访客（非求职用途），重点是个人表达与作品展示。

## 范围（本期）

聚焦把**视觉成型的单页主页**做出来，内容用占位/示例填充：

- ✅ 完整的首页布局与视觉（玻璃质感暖调 Bento）
- ✅ 响应式（手机 / 平板 / 桌面）
- ✅ 工具：**占位卡片**（纯展示，暂不实现具体功能）
- ✅ 文章：**硬编码几篇示例**（标题 + 日期 + 摘要）
- ⬜ 工具的实际功能 —— 后续迭代
- ⬜ 文章系统（Markdown / CMS）—— 后续迭代

## 技术方案

- **纯 HTML / CSS / JS 单页**，无构建步骤、无框架依赖
- 一个 `index.html` 即可运行，可直接部署到 GitHub Pages / Vercel / 任意静态托管
- 字体走 Google Fonts CDN
- 不需要后端

选择理由：个人主页改起来直观、部署零门槛；本期内容多为占位，无需框架的复杂度。后续若工具/文章需要动态能力，再按需升级。

## 视觉规范

确定方向：**玻璃质感暖调 Bento（Glassmorphism Bento）**。

### 布局

- 顶部导航：左 Logo（`James ✦`），右链接（工具 / 作品 / 文章 / 关于）
- 主体为 **4 列 Bento 网格**，混合卡片尺寸：
  - **2×2** Hero 自我介绍卡（头像、姓名、身份、简介、标签）
  - **1×1** 当前状态卡
  - **1×1** GitHub 数据卡
  - **1×1** × 2 工具占位卡
  - **2×1** VIBE 作品精选卡
  - **2×1** 最新文章列表卡
- 卡片圆角 18px，间距 12px
- 响应式：桌面 4 列 → 平板 2 列 → 手机 1 列（卡片依次堆叠，Hero 优先）

### 玻璃效果

- 页面背景：柔白渐变（`#f6f7fb → #faf6f8 → #f5f9f7`）+ 4 团淡雅彩色光斑（蓝/粉/绿/黄）
  - 光斑：不透明度 ~30%、`blur(56px)`、低饱和
- 卡片：磨砂玻璃
  - 半透明白底（不透明度 ~22%）
  - `backdrop-filter: blur(18px) saturate(140%)`
  - 高光描边 `border: 1px solid rgba(255,255,255,0.45)`
  - 柔和阴影 + 内高光
- `backdrop-filter` 需现代浏览器；为不支持的浏览器提供降级（提高白底不透明度）

### 配色（分类色编码）

各卡片用淡色「有色玻璃」对应内容类型，便于快速分区：

| 区域 | 色调 | 含义 |
|------|------|------|
| Hero / 文章 | 蓝 | 主体信息 |
| 状态 | 薄荷绿 | 当前进展 |
| 数据 | 丁香紫 | GitHub 等数据 |
| 工具 | 蜜桃粉 / 暖黄 | 工具入口 |
| 作品 | 浅蓝玻璃 | VIBE 精选 |

强调色：`#6b8fd4`（蓝）系。作品卡用**浅色**玻璃（非深底），保持整体通透明亮。

### 字体

- 标题：**DM Serif Display**（衬线，有个性、温暖）
- 正文：**Nunito**（圆润友好、易读）

### 动效（轻量）

- 卡片 hover：轻微上移 + 阴影扩展（150–300ms，ease-out）
- 可选：光斑缓慢浮动
- 遵守 `prefers-reduced-motion`

## 组件结构（单文件内分区）

1. **导航栏** `<header>` — Logo + 链接
2. **背景层** — 渐变 + 光斑 blob（绝对定位，置于网格之下）
3. **Bento 网格** `<main>` — 各卡片为独立 `<section>`/`<article>`
   - Hero 卡
   - 状态卡 / 数据卡
   - 工具卡 ×2（占位）
   - 作品精选卡
   - 文章列表卡（硬编码数据）
4. **页脚**（可选）— 版权 / 社交链接

每张卡片结构独立、互不依赖，便于以后单独替换或扩展（如把占位工具卡换成真实工具）。

## 数据（本期硬编码）

- **个人信息**：姓名、身份标签、一句话简介
- **状态**：当前在做的项目（一行文字）
- **GitHub 数据**：仓库数、stars（占位数字）
- **工具**：2 张占位卡（图标 + 名称）
- **作品**：1 个精选作品（标题 + 简介）
- **文章**：3 篇示例（日期 + 标题），可附摘要

数据集中放在文件顶部或独立 `<script>` 常量中，方便日后替换为真实内容。

## 可访问性 / 质量基线

- 文字对比度 ≥ 4.5:1（玻璃卡片上的文字需实测，必要时加深）
- 所有可点击元素 `cursor: pointer` + 可见 focus 态
- 图标用 SVG（不用 emoji 作为结构性图标 —— 占位阶段可暂用，正式实现替换为 Lucide/Heroicons）
- 响应式断点：375 / 768 / 1024 / 1440
- 支持 `prefers-reduced-motion`
